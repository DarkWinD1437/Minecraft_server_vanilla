# Gestor de Plugins

Administra los plugins instalados en el servidor Paper.

## Como instalar un plugin
1. Descargar el `.jar` del plugin
2. Copiarlo a la carpeta `datos_mc/plugins/`
3. Hacer clic en **Refrescar** para que aparezca en la lista
4. **Reiniciar el servidor** para que cargue

## Activar / Desactivar
- **Desactivar**: renombra el `.jar` a `.jar.disabled` (Paper lo ignora al iniciar)
- **Activar**: revierte el renombrado
- Siempre reiniciar el servidor para aplicar el cambio

## Ver ping exacto
Con **EssentialsX** instalado, cualquier jugador puede escribir `/ping` en el chat.
Sin plugins, solo los OPs pueden usar `/ping [jugador]` (comando de Paper).

## Coordenadas
Presionar **F3** en el juego muestra coordenadas XYZ, bioma, nivel de luz y mas.
Es igual para todos los jugadores, sin ventajas.

Para coordenadas siempre visibles en pantalla instalar **Coordinates HUD** (ver lista de recomendados).

## Shaders
Los shaders son del lado del cliente — el servidor no interviene.
Cada jugador instala **Iris** (recomendado) u OptiFine en su propio launcher de Minecraft.
